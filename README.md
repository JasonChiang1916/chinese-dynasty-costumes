>
> [English version / 英文版](README.en.md)

## 项目简介

本仓库收录 **中国古代王朝服装图鉴** 全部 760 张服装图，覆盖从商朝到中华民国共 19 个朝代。每一朝代包含成年男、成年女、儿童男、儿童女各 10 套，共 40 套，系统呈现中国服饰从先秦到近现代的形制演变。

所有图片均为 AI 生成的写实风格服装展示图，采用统一的“无头幽灵穿着展示”标准：浅灰背景、正面全身、衣服自己撑出穿着形状，无头、无脸、无手、无假模特、无支架、无衣架、无画面文字。

**在线浏览：** https://jasonchiang1916.github.io/chinese-dynasty-costumes/ （按朝代筛选、搜索款式、点图放大；需在仓库 Settings → Pages 开启 GitHub Pages 后生效）

## 文件命名规则

文件名必须同时包含朝代、性别、成年/儿童、槽位编号，款式名附在最后：

```
{朝代}_{成年/儿童}{男/女}_{编号}_{款式名}.webp
```

示例：`唐_成年男_M01_君主大礼服.webp`、`唐_成年女_F05_襦裙半臂披帛常服.webp`。

新版文件在款式名后加版本号（如 `_v2`），不覆盖旧版。

## 展示标准

全部 760 张图遵循同一展示标准：

- 无头幽灵穿着展示，浅灰背景，正面全身，写实风格
- 无头、无脸、无手、无假模特体、无支架杆、无衣架
- 衣服自己撑出穿着形状；上衣与裤/裙在腰部由衣服直连，无空洞
- 裤脚/裙摆到鞋：腿不露时鞋放在裙摆下；露腿处须用真实人腿/脚踝连进鞋靴
- 禁平铺、禁塑料假体、禁分开摆放、禁画面文字

补充说明：

- 唐朝日常、贵族、歌舞女装为盛唐坦领齐胸版，正式礼服保持端庄
- 中国古代服饰小腿不外露：袍/裙/裤摆盖到鞋口，或以白袜、长靴盖住脚踝
- 贵族成年男鞋：唐以前为有饰舄，唐以后为靴子；中华民国为黑色系带皮鞋
